# Scripts

Helper scripts for development and database operations.

## Scripts

- `run_trustweb.py` - Run TrustWeb scoring
- `seed_mock_data.py` - Seed database with test data
- `inspect_db.py` - Inspect database contents
- `clear_db.py` - Clear database tables
- `run_tarkov.py` - Run Tarkov server

## Usage

```bash
# Run individual scripts
python backend/scripts/run_trustweb.py
python backend/scripts/seed_mock_data.py
```
